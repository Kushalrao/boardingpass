1. OVERVIEW
================================================================================

PROBLEM:
When tracking a flight (e.g., AI2447), users don't know if the aircraft
operating their flight is delayed on its previous journey. If the inbound
aircraft is delayed, the user's flight will likely be delayed too.

SOLUTION:
Use the aircraft's tail number to query all flights for that aircraft today,
identify the inbound flight, and proactively warn users of potential delays.

VALIDATED API:
GET /flex/flightstatus/rest/v2/json/flight/status/tailNumber/{tailNumber}/{year}/{month}/{day}

================================================================================
2. RESEARCH FINDINGS
================================================================================

Tested with 3 different flight patterns:

A) DOMESTIC HIGH-FREQUENCY (Air India AI2447)
   - Aircraft: VT-TQN (Airbus A320neo)
   - Pattern: 8 flights/day across multiple cities
   - Turnaround: 40-60 minutes
   - Delay cascade risk: HIGH

B) LONG-HAUL (Swiss LX147)
   - Aircraft: HB-JHF (Airbus A330-300)
   - Pattern: 2 flights/day (ZRH <-> DEL ping-pong)
   - Turnaround: 1.5 hours
   - Delay cascade risk: LOW

C) MIXED DOMESTIC (IndiGo 6E6832)
   - Aircraft: VT-NHB (Airbus A321neo)
   - Pattern: 5 flights/day across 4 cities
   - Turnaround: Variable (30 mins - 2 hours)
   - Delay cascade risk: MEDIUM

4. API DETAILS
================================================================================

ENDPOINT:
https://api.flightstats.com/flex/flightstatus/rest/v2/json/flight/status/tailNumber/{tailNumber}/{year}/{month}/{day}

PARAMETERS:
- tailNumber: Aircraft registration (e.g., "VT-TQN", "HB-JHF")
- year/month/day: Date to query

AUTHENTICATION:
- appId: (from CiriumConfig)
- appKey: (from CiriumConfig)

RESPONSE CONTAINS:
- flightStatuses[]: Array of all flights for that aircraft
- appendix: Airlines, airports, equipment info

RATE LIMITS:
- Standard API tier (included in Commercial plan)
- Same limits as regular flight status queries

5. EDGE CASES TO HANDLE
================================================================================

1. NO TAIL NUMBER AVAILABLE
   - Some flights don't have tail number until close to departure
   - Show: "Aircraft not yet assigned" message
   - Retry periodically

2. FIRST FLIGHT OF THE DAY
   - No inbound flight exists
   - Show: "First flight of the day for this aircraft"

3. AIRCRAFT SWAP
   - Airline may change aircraft
   - Detect: tailNumber changes between queries
   - Alert user: "Aircraft has been changed"

4. INBOUND FLIGHT CANCELLED
   - Inbound shows status 'C'
   - Alert: "Previous flight cancelled - expect aircraft change or delay"

5. INBOUND FLIGHT DIVERTED
   - Inbound shows status 'D' with different arrival airport
   - Alert: "Previous flight diverted - significant delay expected"

6. MULTIPLE POTENTIAL INBOUNDS
   - Same aircraft, same arrival airport, different times
   - Pick: Latest arrival before user's departure

7. OVERNIGHT AIRCRAFT
   - Aircraft arrived previous day, no flights yet today
   - Query previous day if no inbound found today
   - Show: "Aircraft arrived last night" with that flight info
