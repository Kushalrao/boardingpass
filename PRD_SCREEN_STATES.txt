================================================================================
                              PRODUCT OVERVIEW
================================================================================

Airtime is a flight tracking application that:
- Automatically discovers flights from user's Gmail inbox
- Tracks flights in real-time via Cirium integration
- Provides performance ratings, weather, aircraft details
- Sends push notifications for status changes

================================================================================
                              USER TYPES
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│                           USER TYPE 1: ANONYMOUS USER                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ Definition: User who hasn't signed in with Google                           │
│                                                                              │
│ Capabilities:                                                                │
│   ✓ Can manually add flights                                                │
│   ✓ Can view flight status, weather, equipment details                      │
│   ✓ Can receive push notifications (if they grant permission)               │
│   ✗ Cannot auto-discover flights from Gmail                                 │
│   ✗ Cannot sync across devices                                              │
│   ✗ Data is local/device-bound (Firebase Anonymous Auth)                    │
│                                                                              │
│ Persistence: Firebase Anonymous Auth (survives app restart, not reinstall)  │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                       USER TYPE 2: GOOGLE SIGNED-IN USER                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ Definition: User authenticated via Google Sign-In                           │
│                                                                              │
│ Capabilities:                                                                │
│   ✓ All anonymous user capabilities                                         │
│   ✓ Auto-discover flights from Gmail inbox                                  │
│   ✓ Real-time Gmail monitoring (new bookings auto-added)                    │
│   ✓ Data synced across devices                                              │
│   ✓ Persistent across reinstalls                                            │
│                                                                              │
│ Sub-states:                                                                  │
│   A. Gmail NOT connected (signed in but no Gmail scope granted)             │
│   B. Gmail connected (full functionality)                                   │
│   C. Gmail token expired (needs re-authentication)                          │
│                                                                              │
│ Persistence: Firebase Auth with Google provider, Firestore sync             │
└─────────────────────────────────────────────────────────────────────────────┘

--------------------------------------------------------------------------------
SECTION A: PAGE-LEVEL STATES
--------------------------------------------------------------------------------

┌─────────────────────────────────────────────────────────────────────────────┐
│ STATE 1.1: LOADING STATE                                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ Trigger: Initial app launch, pull-to-refresh, returning from background     │
│                                                                              │
│ UI Requirements:                                                            │
│   - Skeleton loaders for flight cards                                       │
│   - Loading spinner in header/refresh indicator                             │
│   - Disable interactive elements during load                                │
│                                                                              │
│ Duration: Max 10 seconds before showing error/timeout state                 │

┌─────────────────────────────────────────────────────────────────────────────┐
│ STATE 1.2: EMPTY STATE - NO FLIGHTS                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ Trigger: User has no flights added (new user or all flights deleted)        │
│                                                                              │
│ For ANONYMOUS USER:                                                          │
│   - Show illustration/graphic                                               │
│   - Primary CTA: "Add Your First Flight"                                    │
│   - Secondary CTA: "Sign in with Google to auto-import"                     │
│   - Brief explanation of manual add flow                                    │
│                                                                              │
│ For GOOGLE USER (Gmail NOT connected):                                       │
│   - Show illustration/graphic                                               │
│   - Primary CTA: "Connect Gmail to Import Flights"                          │
│   - Secondary CTA: "Or add flight manually"                                 │
│   - Explain auto-import feature benefits                                    │
│                                                                              │
│ For GOOGLE USER (Gmail connected):                                           │
│   - Show illustration/graphic                                               │
│   - Message: "No flights found in your inbox"                               │
│   - Primary CTA: "Add Flight Manually"                                      │
│   - Secondary CTA: "Scan Gmail Again"                                       │
│   - Hint: "Book a flight and we'll find it automatically!"                  │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STATE 1.3: ERROR STATE - FETCH FAILED                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│ Trigger: Firestore read failure, network error, timeout                     │
│                                                                              │
│ UI Requirements:                                                            │
│   - Error illustration/icon                                                 │
│   - User-friendly error message (not technical)                             │
│   - "Retry" button                                                          │
│   - Show cached data if available (with "Last updated X ago" badge)         │
│                                                                              │
│ Error Messages by Type:                                                     │
│   - Network: "No internet connection. Check your network and try again."   │
│   - Timeout: "Taking too long. Please try again."                          │
│   - Server: "Something went wrong. We're working on it."                   │
│   - Auth: "Session expired. Please sign in again."                         │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STATE 1.4: OFFLINE STATE                                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ Trigger: Device loses network connectivity                                  │
│                                                                              │
│ UI Requirements:                                                            │
│   - Persistent banner: "You're offline. Showing cached data."              │
│   - Display cached flights from Firestore offline persistence              │
│   - Disable actions requiring network (refresh, add flight)                │
│   - Auto-refresh when connection restored                                   │
│   - Show "Last synced: X minutes ago"                                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STATE 1.5: GMAIL SYNC IN PROGRESS                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ Trigger: User initiated Gmail scan or background sync running               │
│                                                                              │
│ UI Requirements:                                                            │
│   - Progress indicator in header                                            │
│   - "Scanning emails... X of Y" (if batch info available)                  │
│   - Allow user to continue using app                                        │
│   - New flights appear with subtle animation as discovered                  │
│   - Toast notification when scan completes                                  │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STATE 1.6: GMAIL TOKEN EXPIRED                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ Trigger: Refresh token invalid, user revoked access, token too old          │
│                                                                              │
│ UI Requirements:                                                            │
│   - Non-blocking banner: "Gmail disconnected. Reconnect to keep syncing."  │
│   - CTA button: "Reconnect Gmail"                                          │
│   - Allow manual flight management to continue                              │
│   - Don't block access to existing flights                                  │
└─────────────────────────────────────────────────────────────────────────────┘

--------------------------------------------------------------------------------
SECTION B: FLIGHT LIST ORGANIZATION
--------------------------------------------------------------------------------

┌─────────────────────────────────────────────────────────────────────────────┐
│ CATEGORY 1: NEXT FLIGHT (Hero Section)                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ Definition: The chronologically next upcoming flight                        │
│                                                                              │
│ Display Rules:                                                              │
│   - Show as larger, featured card at top                                    │
│   - Include countdown timer ("Departing in 3h 42m")                         │
│   - Show more details inline (gate, terminal, weather)                      │
│   - Quick action buttons (directions, check-in link)                        │
│                                                                              │
│ Edge Cases:                                                                 │
│   - Flight is TODAY: Highlight prominently, show real-time status          │
│   - Flight departs within 4 hours: Show urgent styling                     │
│   - Flight is currently ACTIVE (in air): Show as "In Flight" with tracker  │
│   - No upcoming flights: Don't show this section                           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ CATEGORY 2: UPCOMING FLIGHTS                                                │
├─────────────────────────────────────────────────────────────────────────────┤
│ Definition: All flights with departure time in the future (excluding next)  │
│                                                                              │
│ Display Rules:                                                              │
│   - Sorted by departure time (soonest first)                               │
│   - Grouped by month/date if many flights                                  │
│   - Standard card size                                                      │
│   - Show: Route, date/time, airline, flight number                         │
│                                                                              │
│ Edge Cases:                                                                 │
│   - Only 1 upcoming flight: Show as "Next Flight" hero, skip this section  │
│   - No upcoming flights: Show "No upcoming flights" with add CTA           │
│   - 10+ flights: Implement pagination or "Show More"                       │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ CATEGORY 3: PAST FLIGHTS                                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ Definition: Flights where arrival time has passed                           │
│                                                                              │
│ Display Rules:                                                              │
│   - Sorted by departure time (most recent first)                           │
│   - Collapsed/minimized by default                                         │
│   - Greyed out or muted styling                                            │
│   - Option to expand section header to view all                            │
│   - Show final status (landed, cancelled, diverted)                        │
│                                                                              │
│ Retention Policy:                                                           │
│   - Keep flights for X months (configurable)                               │
│   - Option to archive or delete                                            │
│   - Show flight count: "Past Flights (12)"                                 │
│                                                                              │
│ Edge Cases:                                                                 │
│   - Flight landed but user hasn't opened app: Mark as complete             │
│   - Cancelled flight: Show with "Cancelled" badge                          │
│   - Diverted flight: Show actual destination                               │
└─────────────────────────────────────────────────────────────────────────────┘

│                                                                              │

│ Visual: Muted/grey styling                                                  │

  □ Flight card: Data loading states (enrichment in progress, partial, failed)

  □ Google user states (Gmail connected/not/expired)

FLIGHT DETAIL PAGE STATES TO HANDLE:
  □ Loading detail state
  □ Flight not found
  □ Refresh in progress
  □ Header: All flight statuses with appropriate styling
  □ Timing: Per flight status (scheduled, delayed, active, landed, cancelled)
  □ Departure airport: Gate, terminal, weather states
  □ Arrival airport: Gate, terminal, weather, baggage states
  □ Performance rating: Available, limited, unavailable
  □ Equipment: Known, code only, unknown, changed
  □ Passenger/booking: Full, partial, manual flight
  □ Live tracker: Available, limited, unavailable (active flights only)
  □ Actions: Context-appropriate per flight status
  □ Alert history: Has alerts, no alerts

  □ Duplicate detection
  □ Multi-segment flights
